# ventilation-expert: 급식실 환기설비 기술 검토

송유성은 이 분야 실무 전문가다. 이 스킬의 역할은 **계산과 근거를 검증 가능한 형태로 정리**하는 것이지, 전문가 판단을 대신하는 것이 아니다.

## 1. 값의 출처를 항상 표시한다
| 표시 | 뜻 | 예 |
|---|---|---|
| [기준] | 법령·지침·설계기준의 값 | 출처 문서명·조항·발행연도를 함께. **모르면 '확인 필요'** |
| [실측] | 현장에서 잰 값 | 측정일, 장비, 측정점 |
| [경험] | 실무 경험칙 | 누구의 경험인지 |
| [추정] | 가정으로 계산한 값 | 가정 내용 |
측정하지 않은 값을 실측처럼 쓰지 않는다. 빈 값은 '미측정'으로 둔다.

## 2. 기본 계산식 (적용 조건을 함께 적는다)
| 항목 | 식 | 비고 |
|---|---|---|
| 풍량 | Q[m³/s] = A[m²] × V[m/s] | m³/h = ×3600, m³/min(CMM) = ×60 |
| 원형 덕트 단면 | A = πD²/4 | |
| 사각 덕트 상당직경 | De = 1.30·(ab)^0.625 / (a+b)^0.25 | 마찰손실 계산용(Huebscher) |
| 동압 | Pv = ρV²/2 ≈ 0.6·V² [Pa] | ρ ≈ 1.2 kg/m³(약 20℃, 1기압). 온도가 높은 배기는 ρ 보정 |
| 속도 ↔ 동압 | V ≈ 1.29·√Pv [m/s] | 같은 ρ 조건 |
| 전압 | Pt = Ps + Pv | |
| 송풍기 축동력 | kW = Q[m³/s] × Pt[Pa] / (1000 × η) | η: 송풍기 효율(카탈로그 값) |
| 상사 법칙 | Q ∝ N, P ∝ N², 동력 ∝ N³ | 같은 송풍기·같은 밀도 |
| 외부식 후드(자유공간) | Q = V·(10X² + A) | DallaValle 식. 플랜지 있으면 약 0.75배. X: 발생원까지 거리, V: 제어풍속 |
| 캐노피 후드 | Q ≈ 1.4·P·H·V | P: 발생원 둘레, H: 높이. 열원·측면 개방 조건 확인 |
제어풍속, 후드 형식별 계수, 급식실 필요 환기량·환기 횟수, 덕트 허용 풍속은 **[기준] 출처 확인이 필요**하다(예: 학교급식 위생관리 지침, 건축물의 설비기준 관련 규칙, 산업환기 설계 기준서 — 최신판과 조항 확인).

## 3. 검토 순서
1. 현황: 조리기구 배치, 후드 형식·치수, 덕트 경로, 송풍기 사양(명판), 급기 유무.
2. 실측: 후드 면풍속·덕트 풍속(피토관 트래버스), 정압, 송풍기 회전수·전류. 측정점·장비 기록.
3. 계산: 필요 풍량(후드 식) ↔ 실측 풍량 ↔ 설계 풍량 비교, 정압 손실 추정, 송풍기 운전점.
4. 원인: 풍량 부족(덕트 누설·필터 막힘·송풍기 성능), 급기 부족(부압), 기류 교란(문·창·급기구 위치) 등 **확인된 것과 추정**을 나눠 쓴다.
5. 개선안: 비용·공사 범위·기대 효과(추정치임을 표시)·검증 방법(개선 후 재측정).

## 4. 기류가시화
연기 발생기, 레이저 시트 등은 **정성 증거**(포집 여부, 역류, 누출 경로)다. 수치 판정 근거로 쓰지 않고, 사진·영상의 촬영 조건을 기록한다. 사진의 얼굴·학교명은 가린다.

## 5. 보고에 넣을 문구
- 계산 결과마다 사용한 식과 가정, 단위.
- "설계 기준 대비 판정"은 기준 출처가 확인된 경우에만. 아니면 "기준 확인 필요"로 둔다.
- 안전·법적 판단(소방, 가스, 구조)은 해당 전문가 확인 대상으로 표시한다.
