# mcp-builder: 외부 도구 연동

## 원칙
- **연결 전 승인**: 어떤 서비스에, 어떤 권한(읽기/쓰기/발송)으로, 어떤 데이터가 오가는지 표로 보여 주고 승인받는다. 실제 고객에게 메시지를 보내는 기능은 반드시 별도 승인.
- **비밀값은 코드에 넣지 않는다**: API 키·토큰은 환경변수나 플랫폼의 비밀 저장소에 두고, 저장소(git)에 올리지 않는다. 채팅에 키를 붙여 넣으라고 하지 않는다.
- 권한은 최소로(읽기만 필요하면 읽기만). 유료 API는 요금과 한도를 먼저 알린다.
- 이미 있는 커넥터(claude.ai 커넥터: Gmail, Google Drive·Sheets·Docs, Calendar 등)가 있으면 새로 만들지 말고 그것을 쓴다.

## 순서
1. 필요 확인: 어떤 일을 자동화하려는지, 기존 커넥터로 되는지 확인한다.
2. 설계: 도구 목록(이름, 입력, 출력, 부작용), 오류 처리, 재시도·속도 제한.
3. 구현: 공식 SDK(TypeScript `@modelcontextprotocol/sdk` 또는 Python `mcp`)로 작은 서버부터. 쓰기·발송 도구는 '미리보기(dry-run)' 모드를 둔다.
4. 시험: 가짜 데이터·시험 계정으로 먼저. 실제 계정은 승인 후.
5. 등록: Claude Code 는 `claude mcp add` 로 등록하고 `claude mcp list` 로 확인한다(옵션은 `claude mcp add --help` 로 확인). claude.ai 에서는 커넥터 설정에서 추가한다.
