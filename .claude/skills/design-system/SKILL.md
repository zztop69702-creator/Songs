# design-system: 송유성 디자인 규칙

## 우선순위
1. **기존 프로젝트의 확정 디자인**이 있으면 그대로 따른다(예: 경험곱하기AI 의 부드러운 교육형 + 빛줄기 연결도). 이 스킬로 덮어쓰지 않는다.
2. 새 프로젝트는 **1안**으로 시작한다. 변경은 시안 이미지를 먼저 보여 주고 승인받는다.

## 스타일: Premium Neo Graphic × Swiss Editorial, B안 그래픽 강조형
- **Swiss Editorial**: 12단 그리드, 왼쪽 정렬, 큰 제목과 넉넉한 여백, 가는 구분선, 숫자·라벨의 위계가 분명한 편집 디자인.
- **Neo Graphic**: 깊은 네이비 바탕 위 선명한 블루 포인트, 큰 숫자, 굵은 도형·선, 절제된 그라데이션과 빛(글로우).
- **B안 그래픽 강조형**: 데이터·도식(흐름선, 게이지, 큰 숫자)을 화면의 주인공으로 둔다. 장식용 이미지는 쓰지 않는다.

## 색 (토큰은 `assets/tokens.css`)
| 시안 | 바탕(네이비) | 포인트 | 용도 |
|---|---|---|---|
| 1안 기본 | `#101E31` | 블루 `#3478F6` | 신뢰·기술 |
| 2안 | `#101E31` | 그린 `#19A66B` | 친환경·설비 개선 |
| 3안 | `#101E31` | 레드 `#EF5555` | 경고·진단·안전 |
- 밝은 면은 흰색·아주 옅은 회청색, 글자는 네이비. 본문 대비 4.5:1 이상을 지킨다(포인트색 위 흰 글씨는 굵게, 큰 글씨에만).
- 다크 모드를 쓸 때는 같은 토큰을 바꿔 끼운다(색을 컴포넌트에 직접 쓰지 않는다).

## 글꼴
| 쓰임 | 글꼴 | 굵기 |
|---|---|---|
| 제목 | Paperlogy | Bold 700 / ExtraBold 800 |
| 본문 | Paperlogy | Regular 400 / Medium 500 |
| 큰 숫자 | Cafe24 PRO Slim | (숫자 전용) |
| 대체 | SUIT → 'Malgun Gothic', 'Apple SD Gothic Neo', sans-serif | |
- 글꼴 파일은 프로젝트 안에 두고 `@font-face` 로 쓴다(오프라인 앱). **상업적 사용 라이선스와 재배포(앱에 포함) 허용 여부는 확인 필요** — 확인 전에는 대체 글꼴로 동작해야 한다.

## 그리드·여백·크기
- 기준 단위 8px. 여백 8/16/24/32/48/64. 카드 모서리 12~16px.
- 본문 16~18px(교육 대상 50~60대면 18px), 줄간격 1.55. 제목 단계 1.25배씩.
- 반응형: 1366px 기준 설계 → 1920 이상은 비례 확대, 900px 미만 1단, 620px 이하 휴대폰.

## 시안 만들기
같은 화면을 1·2·3안 토큰만 바꿔 Playwright 로 캡처해 나란히 보여 준다(앱 파일은 바꾸지 않고 스타일을 덧입혀 캡처). 승인된 안만 실제 파일에 반영한다.
