# contract-docs: 계약 후 제출서류 자동화

## 원칙
- **불확실한 값은 확정하지 않는다.** OCR·추출 결과에는 신뢰도를 붙이고, 낮거나 형식이 맞지 않는 값(금액·날짜·사업자번호·계약번호)은 '검토 필요'로 표시해 사람이 확인한 뒤에만 서류에 넣는다.
- 제출 서류 목록과 양식은 **발주처(학교·교육청)마다 다르다.** 아래 목록은 예시이고, 실제 목록은 발주처 안내문·계약 조건으로 확인한다.
- 개인정보(주민등록번호, 연락처 등)는 필요한 서류에만 넣고, 화면·파일 이름·로그에서는 가린다. 외부 AI 서비스에 원문을 올리기 전에 승인을 받는다.

## 처리 순서
1. 입력: 계약서·과업지시서·발주처 안내문(PDF·사진).
2. 추출 항목: 계약명, 계약번호, 발주처·담당자, 계약 금액(부가세 포함 여부), 계약일·착공일·준공일, 현장 위치, 계약 상대자 정보.
3. 검증: 날짜 순서(계약일 ≤ 착공일 < 준공일), 금액 표기(숫자·한글 금액 일치), 사업자번호 형식, 계약번호 형식. 실패 항목은 '검토 필요'.
4. 서류 생성: 확인된 값만 양식에 채운다. 예시 서류: 착공신고서, 현장대리인 지정·선임 서류, 공정 예정표, 산출 내역서, 보험 가입 증명 관련 서류, 안전·품질 관련 계획서 — **발주처 요구 목록으로 확정**.
5. 일괄 출력: 서류 묶음(PDF·Word)과 누락·검토 필요 목록을 함께 낸다.

## 함께 쓰는 스킬
PDF 읽기·만들기 `pdf`, Word 양식 `docx`, 엑셀 목록 `xlsx`, 앱으로 만들 때 `app-builder`.

## 보고 전 점검
검토 필요 항목 수와 위치 · 사람이 확인한 값만 들어갔는지 · 개인정보 가림 · 발주처별 목록 확인 여부.
