# estimate-builder: 견적·원가·내역 자동화

## 원칙
- **숫자는 출처가 있는 것만**: 단가(물가정보지·표준시장단가·거래 견적), 품(표준품셈 해당 항목), 요율(간접노무비·산재/고용보험·일반관리비·이윤 등)은 연도·발주처마다 바뀐다. 출처와 기준일을 칸으로 둔다. 모르면 빈칸 + '확인 필요'.
- 공공(학교·교육청) 공사는 국가계약법·지방계약법과 발주처 원가계산 기준을 따른다. 상한 요율·절사 규칙은 **최신 기준 확인 필요**로 표시한다.
- 견적 금액의 근거(수량 × 단가)를 모든 행에서 추적할 수 있어야 한다.

## 구성
| 문서 | 내용 |
|---|---|
| 수량 산출서 | 도면·실측에서 수량을 뽑은 근거(길이·개수·면적, 할증) |
| 일위대가 | 단위 작업당 재료·노무·경비 (품셈 항목 번호) |
| 내역서 | 공종별 항목 · 규격 · 단위 · 수량 · 재료비/노무비/경비 단가·금액 |
| 원가계산서 | 재료비 · 노무비(직접·간접) · 경비 · 일반관리비 · 이윤 · 부가세 |
| 견적서·제안서 | 고객용 요약, 포함/제외 범위, 유효기간, 계약 주체·실제 수행자 |

## 자동화 방법
- 엑셀이면 `xlsx` 스킬로 수식을 살려 만든다(값만 붙이지 않는다). 앱이면 `app-builder`.
- 합계 검증: 내역 합계 = 원가계산서 해당 항목, 부가세·절사 후 총액을 다시 계산해 일치 확인.
- 기존 견적 앱(예: TAB 견적서앱)이 있으면 그 계산식과 양식을 그대로 따르고, 바꿀 때는 전후 금액 비교를 보여 승인받는다.
