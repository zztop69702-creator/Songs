# tab-report: 측정자료 정리와 기술 보고서

## 원칙
- **원자료가 기준이다.** 측정 야장(사진·엑셀)의 값을 그대로 옮기고, 옮긴 값은 원자료와 한 번 더 대조한다.
- 빈 측정값은 '미측정', 의심 값은 '재측정 필요'로 표시한다. 보간·추정은 [추정] 표시와 방법을 함께 적는다.
- 판정 기준(예: 설계 대비 허용 편차 %)은 **발주처·적용 기준서에서 확인한 값만** 쓴다. 확인 전에는 '기준 확인 필요'.
- 계산은 `ventilation-expert` 의 식을 쓰고, 단위를 매 표에 적는다.

## 보고서 구성 (기본)
1. 개요: 대상(학교명은 필요 시 가림), 목적, 기간, 수행자, 계약 주체.
2. 측정 장비: 종류, 모델, 교정일(교정 성적서 유무).
3. 측정 방법: 측정 위치·측정점 배치(적용 기준서 명시), 운전 조건(송풍기 회전수, 문·창 상태).
4. 측정 결과 표: 설계값 / 측정값 / 편차(%) = (측정 − 설계) ÷ 설계 × 100 / 판정.
5. 분석: 원인(확인 · 추정 구분), 사진·기류가시화.
6. 개선안과 개선 전후 비교: 같은 조건·같은 측정점으로 비교한 것만 '개선 효과'로 쓴다.
7. 결론과 한계: 측정하지 못한 항목, 조건 차이, 추가 확인 필요 사항.

## 작업 방법
- 엑셀 원자료가 있으면 `xlsx` 스킬, 보고서 파일(Word·PDF)은 `docx`·`pdf` 스킬을 함께 쓴다.
- 표의 합계·평균·편차는 다시 계산해 원자료와 맞는지 확인하고, 반올림 규칙을 표 아래에 적는다.
- 개선 전후 비교는 막대·표로 나란히 두되, 측정 조건이 다르면 그 차이를 표 바로 아래에 적는다.
