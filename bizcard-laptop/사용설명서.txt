[ 영업도우미 노트북용 VER3.0 — 사용설명서 ]

■ 무엇이 바뀌었나 (휴대폰 VER2.0 → 노트북용)
- 상대방 명함 스캔: 웹캠 촬영 / 사진 파일 열기 / 끌어다 놓기 / Ctrl+V 붙여넣기
- 명함 인식(OCR)이 노트북 안에서 처리됩니다. 인터넷이 없어도 되고, 사진이 외부로 나가지 않습니다.
- 인식 항목: 이름·직책·회사·휴대폰·카카오톡 ID·이메일·사무실 번호
- 보낼 명함 3가지(TAB·기류가시화 / 소음캐비닛 / 얼굴명함) 중 원하는 것을 골라 함께 보냄
  (여러 장이면 한 장으로 합쳐서 카톡에 한 번에 붙여넣기 가능)
- 보내기: 카카오톡 PC / 문자(휴대폰과 연결 또는 QR) / Gmail·메일 / 이미지 저장 / Windows 공유
- 연락처 파일(.vcf) 저장, 보낸 기록 자동 저장 + 엑셀(CSV) 내보내기
- 휴대폰 VER2.0 백업 파일을 가져오면 수정한 소개글·내 정보를 그대로 사용

■ 실행 (Windows)
1. 폴더(bizcard-laptop)를 노트북의 아무 곳에 둡니다. (예: 바탕화면)
2. [실행_윈도우.bat] 더블클릭
   - "Windows의 PC 보호" 창이 나오면 [추가 정보] → [실행]
3. Chrome(없으면 Edge)이 자동으로 열립니다. 주소: http://localhost:8765/
4. 검은 창은 쓰는 동안 닫지 마세요. 다 쓰면 닫으면 됩니다.
※ index.html을 그냥 더블클릭해도 열리지만, 그때는 명함 사진 인식만 안 됩니다.

■ 실행 (Mac)
- [실행_맥.command] 더블클릭 (python3 필요. 안 열리면 터미널에서 chmod +x 실행_맥.command)

■ 사용 순서
① 상대방 명함 스캔
   - [웹캠으로 촬영] → 카메라 허용 → 명함을 노란 칸에 꽉 차게 → [촬영] 또는 스페이스바
   - 가장 정확한 방법: 휴대폰으로 찍어 카톡 '나와의 채팅'으로 보냄 → PC 카톡에서 사진을 앱 화면에 끌어다 놓기
   - 인식 결과에서 틀린 곳만 고칩니다. '인식된 글자' 목록의 [이름][회사][휴대폰][카톡] 버튼으로 채울 수도 있습니다.
   - 사진이 옆으로 누웠으면 [90° 돌려서 다시 인식]
② 대표 명함과 소개글(10개 + 직접 작성)을 고르고, 함께 보낼 명함 이미지를 체크
③ 보내기
   [카카오톡 PC]
     1) 친구가 아니면 PC 카톡 → 친구 추가 → ID로 추가 ([카톡 ID 복사] → Ctrl+V)
        번호로 친구 추가는 휴대폰 카톡에서 하는 것이 확실합니다 (.vcf로 연락처 저장 → 자동 친구 추가)
     2) 대화창 열기 → [① 명함 이미지 복사] → Ctrl+V → 전송
     3) [② 소개글 복사] → Ctrl+V → Enter
   [문자]
     - 휴대폰과 연결(Phone Link)이 설정된 노트북: [휴대폰과 연결로 문자] → 번호·글이 채워진 창 → 이미지 Ctrl+V 또는 첨부 → 전송
     - 그 외: [QR → 내 폰에서 문자] → 갤럭시 카메라로 QR 찍기 → 번호·글이 채워진 문자창 → + 로 명함 이미지 첨부 → 전송
   [메일] [Gmail 웹으로 작성] 또는 [기본 메일 앱으로 작성] → 본문에 Ctrl+V(이미지)

■ 문자 자동 발송 (솔라피) — 처음 1번 설정
1. 실행_윈도우.bat로 앱 열기 (index.html 더블클릭으로는 안 됨)
2. 솔라피 콘솔(console.solapi.com) 로그인 → API Key 관리 → 새 API Key 만들기
   → API Key와 API Secret 복사 (Secret은 만들 때 한 번만 보입니다)
3. 앱 ③ 문자(MMS) 칸 → [설정] → API Key, API Secret 붙여넣기, 발신번호 010-6214-7460 확인
   → [저장하고 연결 확인] → "연결 성공 · 잔액 ○○원"이 나오면 끝
   ※ 키는 이 노트북 폴더의 solapi.local.json에 Windows 계정 암호화로만 저장됩니다.
     키를 채팅·카톡·메일로 보내지 마세요. 폴더를 남에게 복사해 줄 때는 이 파일을 빼세요.

■ 문자 자동 발송 — 매번
① 명함 스캔(휴대폰 번호 확인) → ② 명함·소개글 선택 → [명함 이미지 + 소개글 문자 자동 발송]
→ 확인 창에서 받는 사람·이미지·글 확인 (글은 여기서 마지막 수정 가능) → [보내기]
- 처음에는 반드시 본인 번호(010-6214-7460)로 한 번 보내 보고 사진·글이 잘 오는지 확인하세요.
- 사진 MMS 1건 약 110원(VAT 별도, 솔라피 가격표 기준 — 바뀔 수 있음). 잔액은 [설정] 옆에 표시됩니다.
- "접수 완료"는 솔라피가 받았다는 뜻입니다. 실제 도착(성공/실패)은 솔라피 콘솔 > 메시지 내역에서 확인합니다.
- 이미지는 솔라피 MMS 제한(200KB)에 맞춰 자동으로 줄입니다. 명함 3장을 합치면 폰에서 글씨가 작아지니 문자는 1~2장을 권장합니다.
- 실수 방지: 보내기 전 확인 창이 항상 뜹니다. 같은 사람에게 연속으로 누르면 중복 발송되니 주의하세요.

■ 꼭 알아둘 한계 (사실대로)
- 노트북(브라우저)에서는 카카오톡 대화창을 '번호로 자동으로 여는 것'이 불가능합니다.
  카카오가 그런 기능을 공개하지 않기 때문이며, 그래서 '복사 → 붙여넣기' 방식입니다.
- 무료 방식(휴대폰과 연결·QR)은 반자동입니다. 완전 자동은 솔라피(유료) 방식만 가능합니다.
- 문자 이미지는 자동으로 첨부되지 않습니다 (붙여넣기 또는 첨부 버튼).
- 명함 인식은 명함 디자인·조명·화질에 따라 틀릴 수 있습니다. 보내기 전에 번호를 꼭 확인하세요.
- 광고성 문자·카톡은 정보통신망법 기준(수신 동의, '(광고)' 표시, 수신거부 방법 안내 등)을 지켜야 합니다.
  명함을 직접 주고받은 상대에게 보내는 인사·안내 메시지 위주로 쓰세요.
