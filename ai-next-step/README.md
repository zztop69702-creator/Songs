# 경험곱하기AI v1.8 (이전 이름: AI다음행보)

- `dist/경험곱하기AI_v1.8_설치.zip`: 배포용 설치 파일. 압축을 풀고 안의 `.bat`을 더블클릭하면 됩니다.
- `src/`: 설치 파일 안에 들어가는 원본 소스 (`install.ps1`, `app.html`, `app.ico`)
- `build.py`: `src/`를 다시 묶어 `dist/`에 `.bat`과 `.zip`을 만듭니다 → `python build.py`
- `dist/online.html`: 온라인(공유 페이지)용. 설치 ZIP이 들어 있어 상단 'PC 설치 파일 받기' 버튼이 보입니다. 공유 페이지에 올릴 때는 이 파일을 씁니다 (다운로드 권한 필요).
- `original/AI다음행보_v1.7_설치_원본.bat`: 수정 전 원본 (복구용)

## 이름 변경 (v1.8)
- 앱 이름 `경험곱하기AI`, 아이콘은 주황 바탕 `×AI` 글자형입니다.
- 입력값 보존: 입력값은 `%LOCALAPPDATA%\AI다음행보\profile`(앱 전용 브라우저 프로필)에 있으므로 이 저장 폴더 이름은 바꾸지 않았습니다.
- 설치 시 옛 `AI다음행보` 바로가기(바탕화면·시작 메뉴), 옛 앱 파일과 아이콘을 지우고, 비게 된 옛 설치 폴더만 지웁니다.

## 이전 버전으로 되돌리기
`original/AI다음행보_v1.7_설치_원본.bat`을 실행하면 수정 전 앱으로 돌아갑니다 (같은 저장 폴더를 쓰므로 입력값은 유지).
이때 바탕화면에 `경험곱하기AI` 바로가기가 남으니 직접 지우면 됩니다.

## 오류 수정 내역 (app.html만 수정, install.ps1·아이콘은 그대로)
1. 저장값이 이전 버전과 맞지 않거나 깨진 경우 앱이 멈추던 오류 → 답이 빠진 단계로 돌아가게 함 (입력값은 유지)
2. 4단계에서 이미 고른 일을 다시 누르면 자가진단·5요소 수정·학습 체크가 지워지던 오류 → 같은 일을 누르면 유지
3. 2단계에서 이미 고른 경험 유형을 다시 누르면 5요소 수정 내용이 지워지던 오류 → 같은 유형이면 유지
4. 8단계에서 칸을 비우면 카드에 빈 값과 `'' 1건`이 나오던 오류 → 빈 칸은 자동 초안을 사용
5. 조사 오류: `'…전문가'이 가장 높습니다` → `'…전문가'가`, 직접 고친 역할의 `을/를` 자동 선택
6. 클립보드 권한이 막힌 환경에서 복사 실패 → 예전 복사 방식으로 한 번 더 시도

## 디자인 개편 (부드러운 교육형, PC 좌우 2쪽)
- 1쪽(왼쪽, 고정): 지도앱(직업 → 경험×AI → 역량 8칸)이 1쪽 높이 전체를 씁니다. 화면이 작으면 지도앱을 75%까지 줄여 맞추고, 그래도 넘치면 1쪽 안에서만 스크롤됩니다.
- 2쪽(오른쪽): 질문과 답변. 이 쪽만 스크롤되며 이전/다음 버튼은 아래에 늘 보입니다.
- 항상 표시: 진행 단계 목록(상단 1~10), 도움·돌발 버튼(8단계에서만 누를 수 있음), 칸 설명 상자.
- 마지막 단계에서 1쪽 지도앱에도 결론(적용 판단, 나의 정의, 목표 역할, 먼저 배울 것)이 표시됩니다.
- 좁은 화면(900px 미만)은 1쪽과 2쪽을 위아래로 이어서 보여 줍니다 (탭 없이 둘 다 표시).
- 계산식, 문구, 결과 카드, 지침문, 저장 데이터 구조는 바꾸지 않았습니다.

## PC 설치 흐름
1. 온라인 앱 상단 **PC 설치 파일 받기** → `경험곱하기AI_v1.8_설치.zip` 저장 (저장 위치는 브라우저 설정을 따릅니다. 원하는 폴더를 고르려면 브라우저에서 "다운로드 전에 저장 위치 확인"을 켭니다.)
2. ZIP 압축을 풀고 `.bat` 더블클릭 → **설치할 폴더 선택 창** → 바탕화면·시작 메뉴에 아이콘 생성 → 앱 실행 → 설치 완료 창 표시
