# YOUNGIL Acoustic Vision — 스마트 소음보정 V2.0

**15~30초 영상 OCR 기반 비교보정 기능 추가명세서 / Claude Code용**

## 1. 개발 결론

기존 15초 영상 OCR 보정 기능을 15초 기본·최대 30초 연장, 측정조건 검사, 사용자 확인, 독립 검증, 장비별 프로파일 저장 기능으로 확장한다. 기존 영상·FFT·음원위치 기능은 변경하지 않는다.

## 2. 목적 및 적용범위

기준 소음계의 LAeq 결과와 앱의 동시간 구간 LAeq를 비교하여 특정 입력 장비와 조건에서 사용할 소음도 오프셋을 산출한다. 공인 교정이나 마이크 주파수응답 교정을 대체하지 않는다.

## 3. 사용자 절차

① 기준 소음계 모델·교정 이력·A가중·측정시간·측정모드 확인
② 두 마이크를 가능한 한 동일 음장에 설치하고 서로 차폐되지 않도록 배치
③ 앱 측정과 기준 소음계의 적분구간을 동기화해 15초 측정
④ 소음계의 해당 구간 LAeq 결과 화면 촬영 및 OCR 인식
⑤ OCR 결과·단위·모드·구간 확인 후 사용자 승인
⑥ 보정값 계산 후 별도의 측정 구간에서 재검증
⑦ 합격 시 프로파일 활성화, 불합격 시 보류

## 4. 계산 방법

보정 오프셋 C [dB] = LAeq,reference − LAeq,app. 적용값 = LAeq,app + C. 예: 기준 72.5 dB(A), 앱 69.3 dB(A)이면 C=+3.2 dB. 순간 소음계 화면의 산술평균을 LAeq로 간주하지 않는다. 기준 소음계가 LAeq를 지원하지 않으면 간편 비교모드로 분리하고 정확도 한계를 명시한다.

## 5. 지능형 검증 로직

15초 기본 측정. OCR 품질 저하·큰 소음 변동·시간 불일치가 있으면 최대 30초 연장 또는 재측정을 요청한다. 소음계가 최종 LAeq를 표시하는 경우 촬영 시점과 실제 적분구간을 분리하여 기록한다. OCR 값은 반드시 사용자 확인 후 채택한다. 수치 안정성 임계값과 허용오차는 기준장비로 시험하여 확정한다.

## 6. 보정 프로파일 필드

profile_id, 생성일시, 스마트폰 모델, OS, 마이크 종류/식별자, 오디오 입력 경로, 샘플레이트, AGC 등 전처리 상태, 기준 소음계 모델/일련번호/교정일, 가중특성, 기준 측정구간, 기준 LAeq, 앱 LAeq, 오프셋, OCR 신뢰도, 검증구간 오차, 적용상태, 원본 영상 및 데이터 경로, 사용자 승인 이력.

## 7. 실패 및 안전장치

가중특성 불일치, LAeq와 순간값 혼용, 측정구간 불일치, 화면 판독 불확실, 입력 경로 변경, 외장 마이크 탈착, AGC 개입, 신호 포화, 기준장비 정보 누락 시 자동 확정을 금지한다. 자동보정 실패 시 수동 입력과 재시험을 제공한다. 원본값과 보정값을 모두 보존한다.

## 8. 개발 단계 및 완료 기준

PHASE 0: 소음계 LAeq 표시·적분구간·스마트폰 입력경로 확인.
PHASE 1: 보정 UI, 15초 동시 측정, 촬영, OCR, 사용자 확인.
PHASE 2: 30초 연장, 변동성 검사, 오프셋·프로파일 저장.
PHASE 3: 독립 검증구간, 실패처리, 현장 시험.
완료 조건: 동일 구간 비교, OCR 확인, 검증 합격, 원본 추적성, 마이크 변경 시 보정 무효화가 모두 테스트됨.

## 9. Claude Code 실행 지시

기존 YOUNGIL Acoustic Vision 프로젝트에 독립 CalibrationModule을 추가하라. 먼저 기존 구조를 읽고 변경 영향도 및 테스트 계획을 제출하라. 승인 전 기존 기능을 수정하지 말 것. CameraX/AudioRecord 동시 실행과 타임스탬프 정합을 우선 시험하고, OCR은 실제 기준 LAeq 결과 화면을 대상으로 구현하라. 보정 전후 값을 구분 저장하고 실패 시 자동 적용하지 말 것. 각 단계별 구현·시험·미완료 목록을 보고하라.
