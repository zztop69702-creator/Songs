# TEST_PLAN.md — 시험 계획 (Phase 0 ~ 5)

문서 버전: 0.1 (2026-11-10) · 상태: **승인 대기**

## 원칙
- 각 시험 결과는 `TEST_LOG.md`에 기록: 일시, 기종/OS, 장비, 절차, 원시 결과, 판정, 구분(**실측 / 시뮬레이션**).
- 실제 장비 없이 수행한 시뮬레이션·합성신호 시험은 **"시뮬레이션"으로만 표기**하며 실측 검증으로 간주하지 않는다.
- 합격 기준 중 "(제안)"은 초기값이며, 장비 확정 후 사용자와 합의하여 확정한다.

## Phase 1 — 스마트폰 MVP 인수시험
| ID | 시험 | 합격 기준 |
|---|---|---|
| P1-01 | 순음 100 Hz / 350 Hz / 1 kHz / 4 kHz 재생 시 FFT 피크 | 피크 주파수 오차 ≤ Δf (화면 표시값 기준) |
| P1-02 | 스윕 신호에 스펙트로그램 추종 | 시각적 추종 + 피크 로그 확인 |
| P1-03 | BPF 계산 | 입력 rpm·날개수 → 수식값과 일치 (단위시험) |
| P1-04 | 수동 마커 저장·재표시 | 앱 재시작 후 동일 좌표·출처(manual)·시각 표시 |
| P1-05 | 권한 거부 | 카메라/마이크 거부 시 크래시 없이 안내, 재요청 경로 |
| P1-06 | 중단 처리 | 전화 수신·백그라운드 전환·화면 회전 시 데이터 손실 없음 |
| P1-07 | 미교정 표시 | 교정 없을 때 dB(A) 표기 없이 "미교정·상대값" 표시 |
| P1-08 | 레벨 계산 정확도(시뮬레이션) | 합성 WAV(알려진 RMS)로 LAeq/LAFmax 계산값 = 이론값 ± 0.1 dB — **시뮬레이션으로 표기** |
