# YOUNGIL Acoustic Vision

학교 급식실 송풍기·모터·덕트·소음캐비닛의 소음도, 주파수, 음원 위치, 거리, 영상 기록을 통합하는 Android 현장 진단 앱.

> **현재 상태: Phase 0(기술검증 문서) 완료, D-012(Phase 3 = AR 스캔 히트맵 기본) 승인 반영 — Phase 1 착수 승인 대기.** 앱 코드는 아직 없음.
>
> 본 앱의 소음 값은 **참고값**이며 법정·공인 측정을 대체하지 않는다.
