### 배열 선정 기준 [계산 근거: FEASIBILITY §5.2]
- 목표 최저 주파수 f_min에서 원하는 반폭 θ → 필요 개구 D ≈ λ/sin θ. 예: 2 kHz에서 ±20° → D ≈ 0.5 m.
- 앨리어싱 없는 최고 주파수 f_max = c/(2d).
- 두 조건을 동시에 만족하려면 채널 수가 커짐 → 비균일(나선형 등) 배열 검토. **구매 전 파일 기반 시뮬레이션+녹음 검증**.

## 5. 구매 우선순위(안)

1. 즉시(Phase 1): 시험용 Android 폰 2대(보유 기기 우선 활용), 기준 소음계·교정기 보유 확인
2. Phase 1 통과 후: USB 측정 마이크 1개, 삼각대
3. Phase 2: 레이저 거리계(연동 프로토콜 확인 후)
4. Phase 3 검증 단계: 저가 다채널(ReSpeaker급) 1개 또는 다채널 레코더 대여 → 오프라인 알고리즘 검증
5. Phase 3 통과 후에만: 본 배열(UMA-16급 또는 자체 대형 배열)
