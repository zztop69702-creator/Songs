# HARDWARE_MATRIX.md — 장비 후보 비교 (Phase 0)

문서 버전: 0.1 (2026-11-10) · 상태: **승인 대기**

> **주의:** 아래 제품명·사양은 일반적으로 알려진 정보를 바탕으로 한 **후보 목록**이며, 본 검토에서 제조사 데이터시트·가격·국내 구매 가능 여부를 **직접 확인하지 않았다.** 구매 전 반드시 최신 데이터시트와 견적을 확인하고, 실기기 시험(TEST_PLAN) 통과 후 구매한다.
>
> 표기: ✅ 필수 확인 통과 시 채택 / ⚠️ 리스크 있음 / ❌ 용도 부적합

## 1. 구매 순서 원칙
1. **지금(Phase 1 전):** 보유 스마트폰으로 시작. 추가 구매 최소화.
2. **Phase 1~2:** 외장 교정 마이크 1개 + 음향교정기(또는 기준 소음계 대여).
3. **Phase 3 전:** 다채널 녹음 장비 1세트로 **PC 기반 파일 검증** → 통과 시에만 배열·고정 프레임 구매.
4. SPEC §8 원칙대로 마이크 배열 일괄 구매 보류.

## 3. 측정용 단일 마이크 (Phase 1~2)
| 후보 | 형태 | 장점 | 리스크 | 판정 |

| miniDSP UMIK-1 / UMIK-2 | USB 측정 마이크 | 개별 교정파일 제공, 고정 게인, Android OTG 사용 사례 많음 | 교정파일은 제조사 교정(공인 교정 아님), 저주파 하한 확인 필요 | ✅ 1순위 후보 |

## 5-1. Phase 3A AR 스캔 히트맵용 (D-012)
| 장비 | 요구 사항 | 비고 |
|---|---|---|
| ARCore 지원 스마트폰 (Depth 지원 권장) | 6DoF 추적, Depth로 마이크-표면 거리 기록 | §2 표 기준 |
| 외장 교정 마이크 1개 (UMIK-1/2급) | §3 1순위 후보와 동일 | **추가 구매 없음** (Phase 1~2 장비 재사용) |
| 폰-마이크 고정 거치대 + 손잡이 | 마이크가 카메라 시야를 가리지 않고, 폰과 상대 위치 고정 | 마이크 오프셋(폰 기준 위치)을 측정해 설정값으로 입력 |
| 시험용 스피커 2개 | T-18 알려진 음원 위치 시험 | §4 기준 음원과 공용 가능 |

## 6. 다채널 마이크 배열 / 인터페이스 (Phase 3B 선택 확장 — 구매 보류)
선정 기준(FEASIBILITY §6 계산 근거):
- 목표 대역 상한 f_max → 간격 d ≤ λ_min/2 (4 kHz → 약 43 mm)
- 목표 대역 하한 f_min → 배열 폭 D가 분해능 결정 (2 kHz, 20° → 약 0.44 m)
- **동시 샘플링(단일 클럭)**, 채널 간 위상 정합, 원시(raw) 채널 출력 필수

| 후보 유형 | 예시(확인 필요) | 채널/형태 | 장점 | 리스크 | 판정 |
|---|---|---|---|---|---|
| USB 평면 MEMS 배열 보드 | miniDSP UMA-16 계열 | 16ch, 평면 격자 | 단일 클럭, 음향카메라 연구 사례 | 배열 폭이 작아 저주파 분해능 제한, Android 16ch 입력 가능 여부 불명 | ⚠️ PC 검증용 1순위 |
| USB 원형 소형 배열 | miniDSP UMA-8, ReSpeaker 계열 | 4~8ch, 원형 | 저가, 구하기 쉬움 | 기본 펌웨어가 빔포밍 처리 후 1~2ch 출력인 경우 있음 → **raw 펌웨어 필요**, 샘플레이트 제한 가능 | ⚠️ 알고리즘 학습용 |
| 다채널 오디오 인터페이스 + 측정 마이크 n개 | 4~8 입력 USB 인터페이스 / 멀티트랙 레코더 | 4~8ch, 자유 배치 | 배열 폭·간격 자유(저주파용 대형 배열 가능), 마이크 품질 높음 | 부피·케이블, 마이크 간 위상 정합 교정 필요, Android 다채널 입력 불명 | ⚠️ 저주파 실험용 |
| 상용 음향카메라 (임대) | 국내외 상용 제품 | 수십~백여 ch | 검증된 결과, Phase 5 비교 기준 | 고가 — **임대 견적 확인 필요** | ✅ 비교 기준으로 임대 검토 |

## 8. 예산 (SPEC §8 인용, 본 검토에서 재산정하지 않음)
- 초기 시험예산 약 120~950만원(장비·시제품 범위) + 별도 인건비 — **확정 견적 아님**.
- 본 Phase 0에서는 **가격 조사를 수행하지 않았다.** Phase 1 승인 시 구매 대상 항목만 견적 조사 예정.
